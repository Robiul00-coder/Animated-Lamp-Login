## 📌 About The Project

**Animated Lamp Login** is a creative and interactive login page designed with a unique animated lamp concept.

The project combines a modern authentication form with an interactive lamp animation. Users can interact with the lamp to create an engaging login experience.

The design uses a dark background, glowing lamp effects, smooth animations, rounded form elements and a modern purple gradient button.

This project was created to practice **HTML, CSS and JavaScript** while focusing on creative UI design and interactive user experiences.
